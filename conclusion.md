Notebook 1 and Notebook 2 are a good introduction to utlizing the tropycal Python module for analyzing hurricane data. With the example of Hurricane Helene, several functions were learned to create useful figures, such as hurricane track and tornado track maps and rainfall maps. Future work to be done on these notebooks include adding an interactive map of lightning from Hurricane Helene during/after landfall, plotting out cyclone phase space, and overlaying a radar loop on a topographic map to represent orographic lifting that occurred when Helene was post-tropical.
